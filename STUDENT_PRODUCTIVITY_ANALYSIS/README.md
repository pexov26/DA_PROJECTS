# 📊 Student Productivity Analysis

## 📌 Overview

This project analyzes the impact of study habits, distractions, and lifestyle factors on student productivity using data analysis techniques.

## 🎯 Objectives

* Understand relationship between study and sleep
* Analyze impact of distractions
* Identify key factors affecting productivity
* Segment students based on performance

## 🛠️ Tools Used

* Python
* Pandas
* Seaborn
* Matplotlib

## 📊 Key Insights

* Study hours strongly improve productivity
* High distraction reduces productivity
* Focus and sleep positively influence performance
* High performers show disciplined behavior patterns

## 📁 Project Structure

```
student_productivity_analysis/
├── data/
├── notebooks/
├── src/
├── README.md

```

## 🚀 Conclusion

Productivity is influenced by a combination of study habits, focus, and distraction levels. Reducing distractions and improving focus significantly enhances performance.
